# Reproducibility

CONFLICT STONE is reproducible by construction.

- **Determinism.** Every metric is a pure function of a frozen canonical
  dataset. No random draws, no wall-clock dependence in any persisted
  artifact (the provenance block records `wall_time_s = 0`).
- **Provenance.** Every mission outcome carries a package version
  ({{CONFLICT_VERSION}}), a fixed seed, and a SHA-256 fingerprint of the exact
  canonical inputs, so an outcome can be audited without re-running the
  mission.
- **Lineage.** Two end-to-end runs produce byte-identical debriefs; the test
  suite asserts this determinism directly.
- **Recomputation.** The resolved manuscript is generated by re-running
  `scripts/z_generate_manuscript_variables.py` under Python
  {{PYTHON_VERSION}}; the tokens it emits (e.g. provenance coverage
  {{PROVENANCE_COVERAGE_PCT}}, laundering closure
  {{CASINO_LAUNDERING_CLOSURE_PCT}}) are live computations, never hand-stated.
- **Zero mocks.** All tests exercise real computations over real data; the only
  "doubles" are the real canonical datasets themselves.
